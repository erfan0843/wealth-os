# گام‌به‌گام — از سورس تا نصب روی گوشی (بدون سرور)

> هدف: **فایل `app-release.apk`** بساز و روی گوشی نصب کن.
> هیچ سرور/اینترنتِ دائمی لازم نیست — فقط یکبار ساختن روی کامپیوتر.

---

## گام ۱ — فایل سورس را بردار

- فایل: **`wealth-os.zip`** (روی همین صفحه/ورک‌اسپیس).
- آن را به کامپیوترِ خودت منتقل کن (USB / دانلود / تلگرام).

## گام ۲ — باز و آماده کن

**ویندوز:** پوشهٔ زیپ را با کلیک راست → «Extract All».
**مک/لینوکس:**
```bash
cd ~
unzip wealth-os.zip -d wealth-os
cd wealth-os
```

## گام ۳ — اسکریپت خودکفا را اجرا کن (یک دستور)

> پیشنیاز: فقط `git`، `curl`، `unzip` (بیشتر سیستمها دارند). اسکریپت خودش Flutter و Android SDK و JDK 17 را (اگر نبود) نصب و **APK** را میسازد.

```bash
# داخل پوشهٔ wealth-os
bash build-all.sh apk
```
- برای فروشگاه: `bash build-all.sh aab`
- ⏱ زمان ممکن است ۱۰-۳۰ دقیقه (اولین بار، دانلود ابزارها).

## گام ۴ — فایل APK را بردار

```
wealth-os/app/build/app/outputs/flutter-apk/app-release.apk
```
این را به **گوشی** منتقل کن (USB / تلگرام / ایمیل).

## گام ۵ — نصب روی گوشی

1. روی فایل `app-release.apk` در گوشی تپ کن.
2. اگر پیام «نصب از منابع ناشناس» آمد → اجازه بده (Settings → Install unknown apps).
3. نصب تمام → برنامه را باز کن.

---

## سؤالات رایج

**«کامپیوتر باید سرور بماند؟»**
نه. بعد از گام ۴، کامپیوتر هیچ نقشی ندارد. اپ روی گوشی کاملاً **آفلاین** و مستقل است.

**«اگر APK نصب شد ولی خطای Drift داد؟»**
یک‌بار در `wealth-os/app` این را اجرا کن:
```bash
dart run build_runner build
```
سپس `bash build-all.sh apk` را دوباره.

**«خطای OOM / کُندی؟»**
رم ≥۴ گیگ لازم است. اگر کم بود در `app/android/gradle.properties` مقدار `-Xmx` را به `-Xmx2048m` کم کن، یا دستگاه قویتر.

**«اندروید؟»**
اندروید ۷ به بالا (امنیت و کتابخانه‌های پایه). برای iOS این پروژه اندروید است.

## یادآوری صادقانه
- منطق مالی (خرید/فروش/کارمزد/قسط/گزارش/واحد مرجع/پیامک/امنیت) = **درست و ۹۳/۹۳ تست سبز.**
- **صفحههای UI فعلاً نمونهاند** (داشبورد/فرمها) و هنوز به دادهٔ Drift متصل نیستند تا وقتی `build_runner` جدولها را تولید کند (که با `build-all.sh` خودکار میشود). یعنی نسخهٔ فعلی «موتور + ظاهر» است، نه «برنامهٔ کاملاً عملکردی».
