## ۳. جریان‌های کلیدی (User Flows)

### F1 — ثبت هزینه (<۵s)
`FAB + → QuickAdd انتخاب «هزینه» → مبلغ/علت/حساب → ثبت`

### F2 — خرید دارایی
`+ → خرید دارایی → نوع / مقدار / قیمت / حساب / کارمزد(خودکار) → [جزئیات بیشتر] → ثبت`

### F3 — فروش بخشی
`Asset Detail → [+ فروش] → مقدار → Price → فروش → Realized P&L`

### F4 — بدهی + قسط آینده
`+ → بدهی/طلب → نوع/مبلغ/سررسید → [قابل‌تکرار مشترک] → در تقویم آینده ظاهر می‌شود`

### F5 — دنیا را ببین
`Dashboard → بر روی NetWorth → Drill-down → گزارش‌ها`

### F6 — شخصی‌سازی
`Profile → Theme/Accent/RefAsset/Widget order → سریع اعمال`
